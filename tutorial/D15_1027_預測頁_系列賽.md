把 `pages/predict.py` 換成：

> **Jupyter**：新的一格，第一行寫 `%%writefile pages/predict.py`，下面貼這段，執行後就會存成檔案（會覆蓋同名檔案）。

### 2. 奪冠機率卡片

> **Jupyter**：新的一格，第一行寫 `%%writefile -a pages/predict.py`（`-a` 是加到檔案最後面，不會覆蓋），第二行留空，再貼這段。

```python
# ---------- Day 15：系列賽機率 ----------
p_a, results, game_probs = model.simulate_series(
    A["pythag"], B["pythag"], config.TS_HOME_PATTERN, config.TS_NEED, config.HOME_ADVANTAGE)

st.markdown('<p class="eyebrow">系列賽預測 · 蒙地卡羅模擬 10,000 次</p>', unsafe_allow_html=True)
c1, c2 = st.columns(2)
with c1:
    ui.kpi(f"{A_NAME} 奪冠機率", f"{p_a:.0%}", f"畢氏勝率 {ui.f3(A['pythag'])}")
with c2:
    ui.kpi(f"{B_NAME} 奪冠機率", f"{1 - p_a:.0%}", f"畢氏勝率 {ui.f3(B['pythag'])}")
```

`st.columns(2)` 把畫面切成左右兩欄，`with c1:` 裡面的東西會放在左欄。

### 3. 結果分布圖

> **Jupyter**：新的一格，第一行寫 `%%writefile -a pages/predict.py`（`-a` 是加到檔案最後面，不會覆蓋），第二行留空，再貼這段。

```python
order = ["4-0", "4-1", "4-2", "4-3", "3-4", "2-4", "1-4", "0-4"]
fig = go.Figure(go.Bar(
    x=order, y=[results.get(k, 0) / 100 for k in order],
    marker_color=[A["color"]] * 4 + [B["color"]] * 4,
    text=[f"{results.get(k, 0) / 100:.1f}%" for k in order], textposition="outside"))
fig.update_layout(title=f"系列賽結果分布（左邊 {A_NAME} 勝、右邊 {B_NAME} 勝）",
                  yaxis_title="機率（%）", height=320, margin=dict(t=50, b=20),
                  paper_bgcolor="rgba(0,0,0,0)", plot_bgcolor="rgba(0,0,0,0)")
st.plotly_chart(fig, width="stretch")
```

- `results.get(k, 0) / 100`：10,000 次裡出現幾次，除以 100 就是百分比。
- `marker_color`：前四根用 A 隊顏色、後四根用 B 隊顏色，一眼看出哪邊是誰贏。
- `paper_bgcolor="rgba(0,0,0,0)"`：背景透明，融入深色主題。
- `width="stretch"`：圖表撐滿寬度。（舊寫法 `use_container_width=True` 已經要被移除，不要用。）

### 4. 練習：計算說明

用 `st.expander("這個機率怎麼來的？")` 做一個可展開區塊，裡面要有：

1. 三個步驟的文字說明（畢氏勝率 → Log5 → 蒙地卡羅），**數字要從資料帶入**，不要寫死。例如「味全龍得 441 失 371 → .578」。
2. 用 `st.latex()` 顯示畢氏勝率和 Log5 的公式。

提示：中立場地的單場勝率是 `model.log5(A["pythag"], B["pythag"])`。

```python
with st.expander("這個機率怎麼來的？"):
    neutral = model.log5(A["pythag"], B["pythag"])
    st.markdown(f"""
1. **畢氏勝率**：用整季得分與失分估算實力。{A_NAME} 得 {A['RS']} 失 {A['RA']} → {ui.f3(A['pythag'])}；
   {B_NAME} 得 {B['RS']} 失 {B['RA']} → {ui.f3(B['pythag'])}。
2. **Log5**：換算成兩隊對戰的單場勝率。中立場地 {A_NAME} 勝率 {neutral:.1%}，
   主場再加 {config.HOME_ADVANTAGE:.1%}、客場減 {config.HOME_ADVANTAGE:.1%}。
3. **蒙地卡羅模擬**：照七戰四勝和主客場順序，把整個系列賽跑 10,000 次，數每隊贏了幾次。
""")
    st.latex(r"\text{畢氏勝率}=\frac{\text{得分}^{1.83}}{\text{得分}^{1.83}+\text{失分}^{1.83}}"
             r"\qquad P(A)=\frac{A-AB}{A+B-2AB}")
```

`r"..."` 是原始字串，裡面的反斜線 `\` 不會被 Python 當成跳脫字元，LaTeX 公式一定要用。
