## 今天的目標

- 把每位投手「逐場、逐打席」的巢狀紀錄攤平成一張表

## 為什麼要做這一步

整季成績只能看出「這位投手 FIP 3.20」，看不出「他對左打比較弱」「第三輪打線開始被打」。這些弱點要從**每一個打席**統計出來。只要抓全聯盟每位投手面對的所有打席，就等於拿到整個聯盟的每一個打席，打者的資料也一起有了。

### 1. 看一份逐場紀錄長什麼樣子

> **Jupyter**：直接貼在新的一格執行。

```python
from src import fetch
import json

logs = fetch.get_json("https://www.rebas.tw/api/formal/players/PtGe1/seasons/CPBL-2026-oB/logs")["data"]

```

結構是：**一場比賽 → `PA_list`（這場的每個打席）→ `events`（這個打席的每一球）**。

每個打席裡我們要用的欄位：

| 欄位 | 意思 | 例子 |
| --- | --- | --- |
| `batter`、`pitcher` | 打者、投手（名字和代碼） | 高捷 |
| `b_hand`、`p_hand` | 打者左右打、投手左右投 | `L`、`R` |
| `PA_round` | 這是投手第幾輪面對打線 | 1、2、3 |
| `result` | 打席結果 | `1B` 一安、`SO` 三振、`uBB` 四壞、`GO` 滾地出局 |
| `events[].pitch.type` | 每一球的球種 | `FF` 四縫線、`SL` 滑球 |
| `events[].pitch.code` | 每一球的結果 | `B` 壞球、`SW` 揮空、`F` 界外、`H` 打進場內 |

### 2. 攤平函式

加到 `src/fetch.py`：

> **Jupyter**：新的一格，第一行寫 `%%writefile -a src/fetch.py`（`-a` 是加到檔案最後面，不會覆蓋），第二行留空，再貼這段。

```python
# ---------- Day 8：逐打席紀錄 ----------
PA_DIR = RAW_DIR / "pa"

def flatten_pa(logs):
    """把一位投手的逐場紀錄攤平成「一列一個打席」。"""
    rows = []
    for game in logs:
        for pa in game.get("PA_list", []):
            pitches = [e["pitch"] for e in pa.get("events", [])
                       if e.get("type") == "PITCH" and e.get("pitch")]
            rows.append({
                "game_id": game["uniqid"], "date": game["date"],
                "inning": pa.get("inning"), "pa_round": pa.get("PA_round"),
                "batter_id": pa["batter"]["uniqid"], "batter": pa["batter"]["name"],
                "pitcher_id": pa["pitcher"]["uniqid"], "pitcher": pa["pitcher"]["name"],
                "b_hand": pa.get("b_hand"), "p_hand": pa.get("p_hand"),
                "result": pa.get("result"),
                "pitch_types": ",".join(p.get("type") or "" for p in pitches),
                "pitch_codes": ",".join(p.get("code") or "" for p in pitches),
            })
    return rows
```

- 兩層迴圈：外層每場比賽，內層每個打席。
- `events` 裡除了投球，還有換人（`SUB`）等事件，所以只留 `type == "PITCH"` 的。
- 每一球的球種和結果用逗號串成一個字串，例如 `"FF,SL,SL"` 和 `"B,SW,SW"`。這樣一個打席還是一列，之後要拆再 `split(",")`。

### 3. 抓一位投手並快取

一位投手的原始 JSON 大約 1MB，181 位就是 240MB，太大了。所以這裡**不存原始 JSON，只存攤平後的 CSV**：

> **Jupyter**：新的一格，第一行寫 `%%writefile -a src/fetch.py`（`-a` 是加到檔案最後面，不會覆蓋），第二行留空，再貼這段。

```python
def fetch_pitcher_pa(player_id, season=SEASON, refresh=False):
    """一位投手整季面對的每一個打席。原始 JSON 很大（約 1MB），所以只把攤平後的 CSV 存起來。"""
    PA_DIR.mkdir(parents=True, exist_ok=True)
    cache = PA_DIR / f"{season}_{player_id}.csv"
    if cache.exists() and not refresh:
        return pd.read_csv(cache, dtype=str)
    logs = get_json(f"https://www.rebas.tw/api/formal/players/{player_id}/seasons/{season}/logs")["data"]
    df = pd.DataFrame(flatten_pa(logs))
    df.to_csv(cache, index=False)
    return df.astype(str)
```

`dtype=str`：讀回來時全部當文字，避免像 `"1B"` 這種結果、或 `"0012"` 這種代碼被 pandas 自作主張轉成數字。

### 4. 抓全聯盟

新增 `scripts/fetch_all_pa.py`：

> **Jupyter**：新的一格，第一行寫 `%%writefile scripts/fetch_all_pa.py`，下面貼這段，執行後就會存成檔案（會覆蓋同名檔案）。

```python
"""Day 8：抓全聯盟每位投手的逐打席紀錄，合併成 data/clean/pa.csv。第一次執行約 10 分鐘。"""
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent.parent))
import pandas as pd
from src import fetch

pitchers = fetch.fetch_leaders("pitcher")
frames = []
for i, pid in enumerate(pitchers["player_id"], 1):
    frames.append(fetch.fetch_pitcher_pa(pid))
    if i % 20 == 0:
        print(f"{i}/{len(pitchers)}")
pa = pd.concat(frames, ignore_index=True)
out = Path(__file__).resolve().parent.parent / "data" / "clean" / "pa.csv"
out.parent.mkdir(parents=True, exist_ok=True)
pa.to_csv(out, index=False)
print(f"完成：{len(pa)} 個打席 → {out}")
```

- `sys.path.insert(...)`：`scripts/` 裡的程式要能 `from src import ...`，所以把專案根目錄加進 Python 的搜尋路徑。
- `pd.concat(frames)`：把 181 張小表接成一張大表。

> **Jupyter**：可以在格子裡執行，每一行指令前面加 `!`（例如 `!python scripts/update_data.py`）。

```bash

```
