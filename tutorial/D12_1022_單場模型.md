## 今天的目標

- 算出聯盟平均值（每場得分、wOBA、FIP、守備效率）
- 算出每隊的牛棚 FIP 和守備效率（DER）
- 寫 `expected_runs()`：輸入打線和對方投手，預估這一場得幾分
- 用畢氏公式把兩隊預估得分換成勝率

## 為什麼要做這一步

使用者在預測頁選了先發投手和九位打者之後，要能馬上看到「這一場的勝率」。單場模型的想法很直覺：

> **預估得分 ＝ 聯盟每場平均得分 × 打線比平均強多少 × 對方投手比平均弱多少 × 對方守備 × 主客場**

前 6 局對上先發，後 3 局對上牛棚，兩段分開算。

### 1. 聯盟平均值

加到 `src/model.py`：

> **Jupyter**：新的一格，第一行寫 `%%writefile -a src/model.py`（`-a` 是加到檔案最後面，不會覆蓋），第二行留空，再貼這段。

```python
# ---------- Day 12：單場 ----------
def league_context(teams, pitchers, lg_woba):
    """單場模型要用到的聯盟平均值。"""
    ip = pitchers["IP"].sum()
    bip = pitchers["BF"].sum() - pitchers["SO"].sum() - pitchers["BB"].sum() - pitchers["HR"].sum()
    return {"R_per_G": teams["RS"].sum() / teams["G"].sum(),
            "wOBA": lg_woba,
            "FIP": (pitchers["FIP_calc"] * pitchers["IP"]).sum() / ip,
            "DER": 1 - (pitchers["H"].sum() - pitchers["HR"].sum()) / bip}
```

- **加權平均**：FIP 要用局數加權（投 150 局的投手比投 5 局的重要），寫法是 `(FIP × 局數).sum() ÷ 總局數`。
- **DER（守備效率）**：打進場內的球被接殺的比例 ＝ 1 − 場內安打 ÷ 打進場內的球數。打進場內的球數 ≈ 面對打者 − 三振 − 保送 − 全壘打。

### 2. 每隊的牛棚和守備

> **Jupyter**：新的一格，第一行寫 `%%writefile -a src/model.py`（`-a` 是加到檔案最後面，不會覆蓋），第二行留空，再貼這段。

```python
def team_pitching(pitchers):
    """每隊的牛棚 FIP 和守備效率（DER＝打進場內的球被接殺的比例）。"""
    rows = []
    for abbr, g in pitchers.groupby("abbr"):
        pen = g[g["role"] == "後援"]
        bip = g["BF"].sum() - g["SO"].sum() - g["BB"].sum() - g["HR"].sum()
        rows.append({"abbr": abbr,
                     "bullpen_FIP": (pen["FIP_calc"] * pen["IP"]).sum() / pen["IP"].sum(),
                     "DER": 1 - (g["H"].sum() - g["HR"].sum()) / bip})
    return rows
```

`for abbr, g in pitchers.groupby("abbr")`：一次拿到一隊的名字和這隊所有投手。

### 3. 預估得分

> **Jupyter**：新的一格，第一行寫 `%%writefile -a src/model.py`（`-a` 是加到檔案最後面，不會覆蓋），第二行留空，再貼這段。

```python
def expected_runs(woba_vs_sp, woba_all, sp_fip, bullpen_fip, opp_der, ctx,
                  sp_innings=6, home=False):
    """
    預估一隊在這場比賽的得分。
    woba_vs_sp：打線對上「對方先發是左投或右投」的平均 wOBA（前 sp_innings 局）
    woba_all：打線整體 wOBA（對上牛棚的後段局數）
    """
    sp_part = sp_innings / 9 * (woba_vs_sp / ctx["wOBA"]) ** 2 * (sp_fip / ctx["FIP"])
    bp_part = (9 - sp_innings) / 9 * (woba_all / ctx["wOBA"]) ** 2 * (bullpen_fip / ctx["FIP"])
    defense = 1 - (opp_der - ctx["DER"]) * 4
    park = 1.03 if home else 0.97
    return ctx["R_per_G"] * (sp_part + bp_part) * defense * park

def win_prob_from_runs(ra, rb, exp=1.83):
    return pythag(ra, rb, exp)
```

每一項的意思：

| 項目 | 例子 | 效果 |
| --- | --- | --- |
| `(woba / 聯盟 wOBA) ** 2` | 打線 wOBA .340 / .319 → 1.07² ≈ 1.14 | 打線比平均好 7%，得分約多 14%（得分跟上壘、長打是「相乘」的關係，所以取平方） |
| `sp_fip / 聯盟 FIP` | 2.60 / 3.24 → 0.80 | 對方先發很強，得分打 8 折 |
| `defense` | 對方 DER 比平均高 .010 → 0.96 | 對方守備好，得分少 4% |
| `park` | 主場 1.03、客場 0.97 | 主場優勢 |

> 這些係數（平方、×4、1.03）是合理的簡化，不是精確估計。在網站上要誠實說明這是簡化模型。

### 5. 練習：合理性檢查

模型寫好後，一定要用「極端情況」檢查方向對不對：

1. 打線 wOBA 從 .300 提高到 .360，預估得分應該**上升**。
2. 對方先發 FIP 從 2.50 提高到 4.50，預估得分應該**上升**。
3. 兩隊條件完全一樣時，主隊勝率應該**大於 50%**。
