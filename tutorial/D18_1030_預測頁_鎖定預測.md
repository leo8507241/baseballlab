## 為什麼要做這一步

台灣大賽 10/17–10/25 已經在進行或打完了，但我們的模型**只用例行賽資料**，而且你還沒看比分。所以模型現在做的預測，跟賽前做的一模一樣。

問題是：如果之後才說「我的模型預測對了」，別人沒辦法確定你沒有偷看結果再回頭改。研究上的解法叫**預先登記**（pre-registration）：在知道答案之前，把預測寫下來、蓋上時間戳記，之後不能再改。最後一天（11/15）再打開答案對照。

這樣期末報告就能誠實地說：「這是模型在不知道結果的情況下做的預測，最後猜對了多少、猜錯的原因是什麼。」

## 步驟

### 1. 鎖定前的最後檢查

鎖定之後就不能改了，先確認 `src/config.py`：

- `TS_TEAMS`：第一隊是全年勝率最高的味全龍，第二隊是另一支晉級台灣大賽的球隊（Day 4 已經填好）。
- `TS_HOME_PATTERN`：主客場順序。如果不確定，就用預設的 `[True, True, False, False, True, True, True]`（勝率較高的球隊最多 5 場主場）。**不要為了查主客場去看台灣大賽的賽程頁**，那裡會有比分。主客場順序只會稍微影響系列賽機率，實驗 2 會證明這個影響不大；最後一天的逐場對照，會依照**實際**的主客場來比，不受這個設定影響。

### 2. 寫鎖定程式

> **Jupyter**：新的一格，第一行寫 `%%writefile scripts/lock_prediction.py`，下面貼這段，執行後就會存成檔案（會覆蓋同名檔案）。

```python
"""鎖定台灣大賽預測：在看到任何台灣大賽結果之前執行一次，存成 data/clean/prediction_locked.json。"""
import datetime as dt
import json
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
sys.path.insert(0, str(ROOT))
import pandas as pd

from src import config, model

OUT = ROOT / "data/clean/prediction_locked.json"
if OUT.exists():
    sys.exit("已經鎖定過了，不能覆蓋。真的要重做，請先手動刪掉 data/clean/prediction_locked.json")

teams = pd.read_csv(ROOT / "data/clean/teams.csv").set_index("team")
A, B = config.TS_TEAMS
pa, pb = teams.loc[A, "pythag"], teams.loc[B, "pythag"]
p_a, results, _ = model.simulate_series(pa, pb, config.TS_HOME_PATTERN, config.TS_NEED,
                                                 config.HOME_ADVANTAGE)
order = ["4-0", "4-1", "4-2", "4-3", "3-4", "2-4", "1-4", "0-4"]
locked = {
    "locked_at": dt.datetime.now().isoformat(timespec="seconds"),
    "teams": [A, B],
    "pythag": {A: round(pa, 4), B: round(pb, 4)},
    "home_pattern": config.TS_HOME_PATTERN,
    "home_advantage": config.HOME_ADVANTAGE,
    "game_prob_A_home": round(model.game_prob(pa, pb, True, config.HOME_ADVANTAGE), 4),   # A 隊主場時的單場勝率
    "game_prob_A_away": round(model.game_prob(pa, pb, False, config.HOME_ADVANTAGE), 4),  # A 隊客場時的單場勝率
    "champion_prob": {A: p_a, B: round(1 - p_a, 4)},
    "result_dist": {k: results.get(k, 0) / 10_000 for k in order},
    "most_likely": max(results, key=results.get),
}
OUT.write_text(json.dumps(locked, ensure_ascii=False, indent=2), encoding="utf-8")
print(f"已鎖定：{A} 奪冠機率 {p_a:.1%}，最可能的比數 {locked['most_likely']}（{locked['locked_at']}）")
```

重點：

- **只能執行一次**：檔案已經存在時，`sys.exit(...)` 會直接停止，不會覆蓋。這樣預測就不會被不小心改掉。
- `locked_at`：鎖定的時間。`isoformat` 會變成 `2026-10-30T21:30:00` 這種格式。
- `game_prob_A_home`、`game_prob_A_away`：味全龍在主場、客場時的單場勝率。最後一天會依照每場實際的主客場，拿對應的勝率來比。
- `result_dist`：4-0、4-1……0-4 每種比數的機率；`most_likely` 是機率最高的那一種。
- `seed` 跟預測頁一樣（Day 11 預設的 2026），所以鎖定的數字會跟網頁上顯示的一致。
