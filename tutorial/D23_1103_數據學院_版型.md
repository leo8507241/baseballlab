## 今天的目標

- 把每個數據的文字內容放在 `content/stats.json`，跟程式碼分開
- 做出數據學院的版型：左邊選單、右邊數據卡
- 數據卡包含：學習階段、一句話定義、為什麼需要它、什麼時候用、中職實例、公式

## 為什麼要做這一步

數據學院有 14 個數據，每個都有好幾段文字。如果全部寫在 Python 裡，程式會又長又難改。把**內容**放在 JSON 檔、**版型**寫在程式裡，好處是：

- 改文字不用動程式，也不會不小心改壞程式
- 新增一個數據，只要在 JSON 加一筆，頁面自動多一張卡
- 這就是雛形裡說的「每個數據都用同一套格式」

## 步驟

### 1. 設計資料結構

每個數據是一個物件，欄位如下：

| 欄位 | 意思 | 例子 |
| --- | --- | --- |
| `key` | 名稱 | `"wOBA"` |
| `level` | 學習階段 | `"入門"`、`"進階"`、`"高階"` |
| `group` | 分類 | `"打擊"`、`"投球"` |
| `full` | 全名 | `"加權上壘率 Weighted On-Base Average"` |
| `one` | 一句話定義 | |
| `why` | 為什麼需要它 | |
| `use` | 什麼時候用 | |
| `formula` | LaTeX 公式 | |
| `table` | 從哪張表找中職資料 | `"batters"` 或 `"pitchers"` |
| `column` | 對應的欄位 | `"wOBA_calc"` |
| `min_col`、`min` | 樣本門檻 | `"PA"`、`200` |
| `higher_better` | 是否越高越好 | `true`／`false` |
| `fmt` | 數字格式 | `"{:.3f}"` |

### 3. 頁面版型

把 `pages/academy.py` 換成：

```python
import json
from pathlib import Path

import plotly.graph_objects as go
import streamlit as st

from src import metrics, ui
from src.data import load

ui.setup("數據學院")
teams, batters, pitchers, const, lg = load()
STATS = json.loads((Path(__file__).resolve().parent.parent / "content" / "stats.json").read_text(encoding="utf-8"))
TABLES = {"batters": batters, "pitchers": pitchers}

levels = ["入門", "進階", "高階"]
nav, main = st.columns([1, 4])
with nav:
    key = st.radio("選擇數據", [s["key"] for s in STATS],
                   format_func=lambda k: "{0[group]}｜{0[key]}（{0[level]}）".format(
                       next(s for s in STATS if s["key"] == k)))
s = next(x for x in STATS if x["key"] == key)
df = TABLES[s["table"]]
df = df[df[s["min_col"]] >= s["min"]]
col = s["column"]
fmt = ui.f3 if s["fmt"] == "{:.3f}" else s["fmt"].format   # 三位小數用棒球習慣：.320

with main:
    st.markdown(" → ".join(f"**{l}**" if l == s["level"] else l for l in levels))
    st.header(f"{s['key']}　{s['full']}")
    st.markdown(f"#### {s['one']}")
    c1, c2 = st.columns(2)
    c1.markdown(f'<div class="card"><p class="eyebrow">為什麼需要它</p>{s["why"]}</div>', unsafe_allow_html=True)
    c2.markdown(f'<div class="card"><p class="eyebrow">什麼時候用</p>{s["use"]}</div>', unsafe_allow_html=True)
```

- `st.columns([1, 4])`：左右比例 1:4，左邊窄的放選單。
- `format_func`：選單上顯示「打擊｜wOBA（進階）」。`"{0[group]}".format(物件)` 是取物件裡 `group` 欄位的寫法。
- `fmt`：`ui.f3` 會把 0.320 顯示成 `.320`；其他格式（例如 `"{:.1f}%"`）就用字串的 `.format`。
- 上面那行「入門 → **進階** → 高階」就是學習路徑，目前這個數據屬於哪一階會變粗體。
