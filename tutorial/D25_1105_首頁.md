### 2. 練習：球季數據亮點

做 4 張 `ui.kpi` 卡片，一列排開：

| 卡片 | 怎麼找 | 標籤 |
| --- | --- | --- |
| wOBA 最高 | 打席 300 以上，`wOBA_calc` 最大 | 無 |
| ERA 與 FIP 落差最大 | 投球 50 局以上，`ERA − FIP_calc` 最大 | 藍色「運氣差」 |
| 先發三振率最高 | 投球 50 局以上的先發，`Kp` 最大 | 綠色「聯盟第 1」 |
| BABIP 最高 | 打席 300 以上，`BABIP` 最大 | 紅色「可能有運氣成分」 |

卡片下方顯示「球隊・球員名字」。

st.header("球季數據亮點")

### 3. 戰績表

```python
st.header("全年戰績")
show = teams[["rank", "team", "W", "L", "T", "PCT", "RS", "RA", "pythag", "luck"]]
st.dataframe(show, hide_index=True, width="stretch", column_config={
    "rank": "排名", "team": "球隊", "PCT": st.column_config.NumberColumn("勝率", format="%.3f"),
    "RS": "得分", "RA": "失分",
    "pythag": st.column_config.NumberColumn("畢氏勝率", format="%.3f"),
    "luck": st.column_config.NumberColumn("實際 − 畢氏", format="%+.3f",
                                          help="正數代表贏得比得失分差應有的多，可能有運氣成分")})
st.caption("資料來源：野球革命 Rebas、中華職棒官方網站")
```

- `st.column_config`：設定每一欄的中文名稱和數字格式，表格就不用另外改欄位名稱。
- `format="%+.3f"`：強制顯示正負號。
- `help=...`：滑鼠移到欄位名稱上會出現說明，這就是雛形裡「名詞提示」的簡單版本。

### 4. 中職官網的上下半季戰績

Day 7 已經把半季戰績存成 `data/clean/half_standings.csv`。先在 `src/data.py` 最後面加一個讀取函式：

```python
@st.cache_data
def load_half():
    """中職官網的上下半季戰績（Day 25）；沒有檔案就回傳 None。"""
    path = CLEAN / "half_standings.csv"
    return pd.read_csv(path) if path.exists() else None
```

檔案不存在時回傳 `None`，頁面就不顯示這一區，不會報錯。

在首頁戰績表下面、`st.caption("資料來源…")` 上面加：

```python
half = load_half()
if half is not None:
    st.subheader("上下半季戰績")
    c1, c2 = st.columns(2)
    for col, name in [(c1, "上半季"), (c2, "下半季")]:
        h = half[half["half"] == name].copy()
        h["PCT"] = h["W"] / (h["W"] + h["L"])
        h = h.sort_values("PCT", ascending=False)
        col.markdown(f"**{name}**（冠軍：{h.iloc[0]['team']}）")
        col.dataframe(h[["team", "W", "L", "T", "PCT"]], hide_index=True, width="stretch", column_config={
            "team": "球隊", "PCT": st.column_config.NumberColumn("勝率", format="%.3f")})
    st.caption(f"半季戰績來源：{half['source'].iloc[0]}，並已跟野球革命的全年戰績交叉比對")
```

- 兩欄並排：左邊上半季、右邊下半季，各自依勝率排序，第一名就是半季冠軍。
- 最下面一行標出**資料來源**：正常是「中職官網」；官網抓不到時，會顯示「野球革命（備案）」。讓讀者知道數字從哪裡來，是資料網站的基本禮貌。
