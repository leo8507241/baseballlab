## 為什麼要做這一步

企劃書的資料來源是「中職官網和野球革命同步進行」。兩個來源各有用處：

| 來源 | 拿得到什麼 | 特點 |
| --- | --- | --- |
| 中職官網 | 上下半季戰績 | 官方數字；但資料頁在海外網路會被導回首頁 |
| 野球革命 | 全年戰績、球員成績、逐打席紀錄 | 有 API，資料最完整 |

半季戰績很重要：中職是上下半季各出一個冠軍，季後賽的資格就是這樣決定的。用兩個來源互相驗證，也是資料工程很重要的習慣：**一個數字如果兩個來源都對得上，才比較可信**。

今天也會學第二種爬蟲方法：Day 2–4 是抓 API 回傳的 JSON，今天是解析網頁的 HTML。

### 3. 新增 `src/cpbl.py`，下載首頁

```python
"""中職官網（cpbl.com.tw）：抓首頁上的上、下半季戰績，並跟野球革命交叉比對。

官網的資料頁（全紀錄、賽程、Box）在海外網路會被導回首頁，首頁的戰績表則可以讀到。
抓不到時，改用野球革命的比賽結果自己算（Plan B）。
"""
import pandas as pd
import requests
from bs4 import BeautifulSoup

from src.fetch import HEADERS, RAW_DIR, fetch_games

CPBL_HOME = "https://www.cpbl.com.tw/"
HALF_GAMES = 180            # 全年 360 場，第 1–180 場是上半季


def fetch_cpbl_home(refresh=False):
    """下載中職官網首頁的 HTML，存一份到 data/raw。"""
    cache = RAW_DIR / "cpbl_home.html"
    if cache.exists() and not refresh:
        return cache.read_text(encoding="utf-8")
    res = requests.get(CPBL_HOME, headers=HEADERS, timeout=20)
    res.raise_for_status()
    cache.parent.mkdir(parents=True, exist_ok=True)
    cache.write_text(res.text, encoding="utf-8")
    return res.text
```

跟 Day 3 的 `cached_json` 一樣有快取，只是存的是 HTML 文字。`HEADERS`、`RAW_DIR`、`fetch_games` 直接從 `fetch.py` 拿來用，不重複寫。

### 4. 解析戰績表

打開開發者工具的 **Elements** 分頁，用左上角的箭頭點戰績表，會看到它是一個 `<table>`：表頭有「勝率」，每一列的球隊名稱放在 `<a title="味全龍">` 裡，第三格是「39-21-0」這種勝-敗-和。

```python
def parse_half_standings(html):
    """從首頁 HTML 找出「有勝率欄位」的表格；第一張是上半季、第二張是下半季。"""
    soup = BeautifulSoup(html, "html.parser")
    rows = []
    tables = [tb for tb in soup.find_all("table")
              if "勝率" in [th.get_text(strip=True) for th in tb.find_all("th")]]
    for half, tb in zip(["上半季", "下半季"], tables):
        for tr in tb.find_all("tr")[1:]:
            team = tr.find("a", title=True)
            tds = [td.get_text(strip=True) for td in tr.find_all("td")]
            if not team or len(tds) < 4:
                continue
            w, l, t = (int(x) for x in tds[2].split("-"))
            rows.append({"half": half, "team": team["title"], "W": w, "L": l, "T": t})
    return pd.DataFrame(rows)
```

- `BeautifulSoup(html, "html.parser")`：把 HTML 文字變成可以搜尋的結構。
- `soup.find_all("table")`：找出所有表格。首頁有好幾張表格，所以用「表頭有勝率」來篩選出戰績表。
- `tr.find("a", title=True)`：找這一列裡有 `title` 屬性的連結，它的 `title` 就是隊名。
- `tds[2].split("-")`：把「39-21-0」拆成勝、敗、和三個數字。
- `zip(["上半季", "下半季"], tables)`：第一張表是上半季、第二張是下半季。

測試：

```bash
python -c "from src import cpbl; print(cpbl.parse_half_standings(cpbl.fetch_cpbl_home()))"
```

應該印出 12 列：上半季、下半季各 6 隊。上半季冠軍味全龍 39-21，下半季冠軍中信兄弟 36-24。

### 5. 練習：Plan B，用野球革命自己算

如果官網抓不到，就用 Day 4 的 `fetch_games()` 自己算。寫 `half_standings_from_rebas()`，回傳跟上面一樣格式的表格（`half`、`team`、`W`、`L`、`T`）。

提示：

- 一季 360 場，**第 1–180 場是上半季**（用 `seq` 欄位判斷）。
- 主隊贏是 `winner_side == "HOME"`，客隊贏是 `"AWAY"`，和局是 `"TIE"`。

> 為什麼不用日期切（例如 7/3 之前算上半季）？因為延賽的比賽會在之後補賽。用日期切的話，統一和兄弟會有 1 場被算到錯的半季，跟官網對不上。用場次編號才對得上。

<details>
<summary>參考解答</summary>

```python
def half_standings_from_rebas():
    """Plan B：用野球革命的比賽結果，依「第幾場」切成上下半季自己算。"""
    games = fetch_games()
    games["half"] = games["seq"].astype(int).map(lambda s: "上半季" if s <= HALF_GAMES else "下半季")
    rows = []
    for half, g in games.groupby("half"):
        for team in pd.unique(g[["away", "home"]].values.ravel()):
            m = g[(g["away"] == team) | (g["home"] == team)]
            win = (((m["home"] == team) & (m["winner_side"] == "HOME"))
                   | ((m["away"] == team) & (m["winner_side"] == "AWAY"))).sum()
            tie = (m["winner_side"] == "TIE").sum()
            rows.append({"half": half, "team": team, "W": int(win), "L": int(len(m) - win - tie), "T": int(tie)})
    return pd.DataFrame(rows)
```

- `games[["away", "home"]].values.ravel()`：把客隊、主隊兩欄攤平成一串，再 `pd.unique` 取出所有球隊。
- 每一隊找出自己參與的比賽，數主場贏和客場贏的場數。

### 6. 先試官網，失敗才用 Plan B

```python
def half_standings(refresh=False):
    """先試中職官網，失敗才用野球革命。回傳（表格, 來源）。"""
    try:
        df = parse_half_standings(fetch_cpbl_home(refresh))
        if len(df) == 12:
            return df, "中職官網"
        print(f"官網戰績表只解析到 {len(df)} 列，改用野球革命")
    except requests.RequestException as e:
        print(f"中職官網連線失敗（{e}），改用野球革命")
    return half_standings_from_rebas(), "野球革命（備案）"
```

這就是「官網優先、野球革命備案」：`try` 裡面先抓官網，連線失敗（`except`）或解析出來的列數不對，都改用 Plan B。回傳時順便告訴你資料來自哪裡，網站上可以標示來源。

### 7. 交叉比對

```python
def cross_check(half, season):
    """上半季 + 下半季 應該等於野球革命的全年戰績；回傳對不上的球隊。"""
    total = half.groupby("team")[["W", "L", "T"]].sum()
    full = season.set_index("team")[["W", "L", "T"]]
    diff = (total - full).abs().sum(axis=1)
    return diff[diff > 0]
```

`half.groupby("team")[["W", "L", "T"]].sum()` 把上下半季加起來，再減掉野球革命的全年戰績。全部是 0 就代表兩個來源一致。

```bash
python -c "
from src import cpbl, fetch
half, source = cpbl.half_standings()
print(source)
print('對不上的球隊：', cpbl.cross_check(half, fetch.fetch_standings()).to_dict())
print('Plan B 跟官網差多少：', (cpbl.half_standings_from_rebas().set_index(['half','team']).sort_index()
      - half.set_index(['half','team']).sort_index()).abs().sum().sum())
"
```

應該印出「中職官網」、空的 `{}`（全部對得上），以及 Plan B 跟官網差 0。
