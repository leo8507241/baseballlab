# Day 1｜10/11（日）｜環境建置與第一個網頁

> 預計時間：2 小時　｜　階段：資料基礎

## 今天的目標

- 建立專案資料夾結構
- 建立獨立的 Python 虛擬環境，裝好要用的套件
- 用 Git 管理版本，並推上 GitHub
- 跑出第一個 Streamlit 網頁

## 為什麼要做這一步

這個網站會用到 6 個套件，每個套件都有版本差異。虛擬環境讓這個專案的套件跟電腦上其他專案（例如 CPBL Dashboard）互不影響；部署到 Hugging Face 時，也是照 `requirements.txt` 安裝同樣的版本。

## 步驟

### 1. 建立資料夾結構

這份教學放在 `好球帶研究室/tutorial/`，專案就建在 `好球帶研究室/` 裡面。打開終端機：

```bash
cd ~/Desktop/線上課程教材/pythan基礎觀念/爬蟲/好球帶研究室
mkdir -p src pages scripts content data/raw data/clean .streamlit
touch src/__init__.py
```

- `src/`：所有計算邏輯（爬蟲、公式、模型）
- `pages/`：網站頁面，只負責「顯示」
- `data/raw/`：爬下來的原始資料；`data/clean/`：整理好、網站要讀的資料
- `src/__init__.py`：空檔案，讓 Python 把 `src` 當成一個套件，之後才能寫 `from src import fetch`

### 2. 建立虛擬環境

```bash
python3 -m venv .venv
source .venv/bin/activate
```

成功的話，終端機開頭會多出 `(.venv)`。**之後每次開新的終端機都要先執行 `source .venv/bin/activate`。**

### 3. 安裝套件

新增檔案 `requirements.txt`：

```text
streamlit==1.51.0
pandas==2.3.3
numpy==2.3.5
plotly==6.3.0
requests==2.32.5
beautifulsoup4==4.13.5
```

```bash
pip install -r requirements.txt
```

為什麼要寫死版本（`==`）？因為 Streamlit 改版很快，部署時如果裝到不同版本，同一份程式碼可能就壞掉。

### 4. 第一個網頁

新增 `app.py`：

```python
import streamlit as st

st.set_page_config(page_title="好球帶研究室", page_icon="⚾", layout="wide")
st.title("好球帶研究室")
st.write("用進階數據，看懂中職。")
```

```bash
streamlit run app.py
```

瀏覽器會自動打開 `http://localhost:8501`。改一下 `st.write` 的文字再存檔，網頁右上角會出現「Rerun」，點下去就會更新。按 `Ctrl + C` 關掉伺服器。

### 5. 用 Git 管理版本

新增 `.gitignore`（告訴 Git 哪些檔案不要管）：

```text
.venv/
__pycache__/
data/raw/
.DS_Store
```

`data/raw/` 不上傳，因為原始資料很大，而且隨時可以重新爬。`data/clean/` 要上傳，因為部署後的網站要讀它。

```bash
git init
git add .
git commit -m "Day 1: 專案初始化"
```

> 這個資料夾在 `爬蟲/` 裡面，而 `爬蟲/` 本身也是一個 Git 專案。為了不互相干擾，在 `爬蟲/.gitignore` 最後加一行 `好球帶研究室/`，外層專案就不會管這個資料夾。

### 6. 推上 GitHub

1. 到 GitHub 建一個新的 repository，名稱例如 `haoqiudai-lab`，**不要**勾選「Add a README」。
2. 照 GitHub 頁面上的指示：

```bash
git remote add origin https://github.com/<你的帳號>/haoqiudai-lab.git
git branch -M main
git push -u origin main
```

## 常見錯誤

| 狀況 | 原因與解法 |
| --- | --- |
| `command not found: streamlit` | 沒有啟動虛擬環境，先 `source .venv/bin/activate` |
| `pip install` 裝到別的地方 | 用 `which python` 確認路徑在 `.venv` 裡面 |
| `git push` 要求密碼 | GitHub 不再接受密碼，要用 Personal Access Token，或改用 GitHub Desktop |
