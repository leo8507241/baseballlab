> 預計時間：2 小時　｜　階段：資料基礎

## Jupyter 版做法

Day 1 在**終端機**完成：建立資料夾、虛擬環境、安裝套件、Git。最後的第 7 步會設定 JupyterLab，**從 Day 2 開始改用 Jupyter**。

## 今天的目標

- 建立專案資料夾結構
- 建立獨立的 Python 虛擬環境，裝好要用的套件
- 用 Git 管理版本，並推上 GitHub
- 跑出第一個 Streamlit 網頁
- 設定 JupyterLab，之後每天在 Jupyter 裡寫程式

## 為什麼要做這一步

這個網站會用到 6 個套件，每個套件都有版本差異。虛擬環境讓這個專案的套件跟電腦上其他專案（例如 CPBL Dashboard）互不影響；部署到 Hugging Face 時，也是照 `requirements.txt` 安裝同樣的版本。

## 步驟

### 1. 建立資料夾結構

這份教學放在 `好球帶研究室/tutorial/`，專案就建在 `好球帶研究室/` 裡面。打開終端機：

> **一定要在終端機執行**：Day 1 還在設定環境，Jupyter 要到最後一步才設定好。

```bash
cd ~/Desktop/線上課程教材/pythan基礎觀念/爬蟲/好球帶研究室
mkdir -p src pages scripts content data/raw data/clean .streamlit
touch src/__init__.py
```

- `src/`：所有計算邏輯（爬蟲、公式、模型）
- `pages/`：網站頁面，只負責「顯示」
- `data/raw/`：爬下來的原始資料；`data/clean/`：整理好、網站要讀的資料
- `src/__init__.py`：空檔案，讓 Python 把 `src` 當成一個套件，之後才能寫 `from src import fetch`

### 2. 建立虛擬環境

> **一定要在終端機執行**：Day 1 還在設定環境，Jupyter 要到最後一步才設定好。

```bash
python3 -m venv .venv
source .venv/bin/activate
```

成功的話，終端機開頭會多出 `(.venv)`。**之後每次開新的終端機都要先執行 `source .venv/bin/activate`。**

### 3. 安裝套件

新增檔案 `requirements.txt`：

> **一定要在終端機執行**：Day 1 還在設定環境，Jupyter 要到最後一步才設定好（用文字編輯器或 `cat > requirements.txt <<'EOF'` 建立）。

```text
streamlit==1.51.0
pandas==2.3.3
numpy==2.3.5
plotly==6.3.0
requests==2.32.5
beautifulsoup4==4.13.5
```

> **一定要在終端機執行**：Day 1 還在設定環境，Jupyter 要到最後一步才設定好。

```bash
pip install -r requirements.txt
```

為什麼要寫死版本（`==`）？因為 Streamlit 改版很快，部署時如果裝到不同版本，同一份程式碼可能就壞掉。

### 4. 第一個網頁

新增 `app.py`：

> **一定要在終端機執行**：Day 1 還在設定環境，Jupyter 要到最後一步才設定好（用文字編輯器或 `cat > app.py <<'EOF'` 建立）。

```python
import streamlit as st

st.set_page_config(page_title="好球帶研究室", page_icon="⚾", layout="wide")
st.title("好球帶研究室")
st.write("用進階數據，看懂中職。")
```

> **一定要在終端機執行**：網站會一直執行，用 `!` 跑會讓 notebook 卡住。在 JupyterLab 用 **File → New → Terminal** 開一個終端機執行。

```bash
streamlit run app.py
```

瀏覽器會自動打開 `http://localhost:8501`。改一下 `st.write` 的文字再存檔，網頁右上角會出現「Rerun」，點下去就會更新。按 `Ctrl + C` 關掉伺服器。

### 5. 用 Git 管理版本

新增 `.gitignore`（告訴 Git 哪些檔案不要管）：

> **一定要在終端機執行**：Day 1 還在設定環境，Jupyter 要到最後一步才設定好。

```text
.venv/
__pycache__/
data/raw/
.DS_Store
```

`data/raw/` 不上傳，因為原始資料很大，而且隨時可以重新爬。`data/clean/` 要上傳，因為部署後的網站要讀它。

> **一定要在終端機執行**：Day 1 還在設定環境，Jupyter 要到最後一步才設定好。

```bash
git init
git add .
git commit -m "Day 1: 專案初始化"
```

> 這個資料夾在 `爬蟲/` 裡面，而 `爬蟲/` 本身也是一個 Git 專案。為了不互相干擾，在 `爬蟲/.gitignore` 最後加一行 `好球帶研究室/`，外層專案就不會管這個資料夾。

### 6. 推上 GitHub

1. 到 GitHub 建一個新的 repository，名稱例如 `haoqiudai-lab`，**不要**勾選「Add a README」。
2. 照 GitHub 頁面上的指示：

> **一定要在終端機執行**：第一次推送可能要輸入帳號和 token，`!` 沒辦法輸入。在 JupyterLab 用 **File → New → Terminal** 開一個終端機執行。

```bash
git remote add origin https://github.com/<你的帳號>/haoqiudai-lab.git
git branch -M main
git push -u origin main
```

### 7. 設定 JupyterLab（從 Day 2 開始每天用）

之後的程式碼都可以在 JupyterLab 裡寫和除錯。這一步讓 JupyterLab 使用這個專案的虛擬環境，而不是 Anaconda 的 Python。

**(1) 讓 Jupyter 認得專案的虛擬環境**

> **在終端機執行**：Day 1 還在設定環境。

```bash
source .venv/bin/activate
pip install ipykernel
python -m ipykernel install --user --name haoqiudai --display-name "好球帶研究室 (.venv)"
```

- `ipykernel`：讓 Jupyter 可以使用這個虛擬環境裡的套件。它只在你的電腦上開發時用，所以不寫進 `requirements.txt`。
- 最後一行是向 Jupyter 登記這個環境，名稱叫「好球帶研究室 (.venv)」。

**(2) 準備放筆記本的資料夾，並讓 Git 忽略 Jupyter 的暫存檔**

> **在終端機執行**：Day 1 還在設定環境。

```bash
mkdir -p notebooks
echo ".ipynb_checkpoints/" >> .gitignore
```

**(3) 啟動 JupyterLab**

> **一定要在終端機執行**：JupyterLab 要從**已經啟用 `.venv` 的終端機**啟動，筆記本裡的 `!python`、`!pip` 才會用到專案的環境；直接從 Anaconda Navigator 打開的話，`!pip install` 會把套件裝到 Anaconda 裡。

```bash
jupyter lab
```

瀏覽器會自動打開 JupyterLab。這個終端機分頁會一直被 JupyterLab 佔用，不要關掉。

**(4) 建立第一個筆記本**

在 JupyterLab 左側進入 `notebooks` 資料夾，按 **File → New → Notebook**，Kernel 選「好球帶研究室 (.venv)」，存檔名稱 `D01.ipynb`。在第一格貼上「每日開場程式碼」並執行：

> **Jupyter**：直接貼在新的一格執行。之後每天的筆記本，第一格都放這段。

```python
%cd ~/Desktop/線上課程教材/pythan基礎觀念/爬蟲/好球帶研究室
%load_ext autoreload
%autoreload 2
import sys
print(sys.executable)
```

- `%cd`：把筆記本的工作位置切到專案根目錄。筆記本放在 `notebooks/` 裡，切過去之後 `from src import fetch`、`data/clean/...` 這些路徑才會對。
- `%load_ext autoreload` 和 `%autoreload 2`：之後修改 `src/` 裡的 `.py` 檔，不用重新啟動 kernel 就會套用新版本。
- 最後印出的路徑結尾要是 `好球帶研究室/.venv/bin/python`。如果是 `/opt/anaconda3/...`，代表 Kernel 選錯了，到右上角重新選「好球帶研究室 (.venv)」。

再開一格確認 `!` 指令也用到專案的環境：

> **Jupyter**：直接貼在新的一格執行。

```python
!which python
```

結尾同樣要是 `.venv/bin/python`。如果不是，代表 JupyterLab 不是從啟用 `.venv` 的終端機啟動的，回到 (3) 重新啟動。

**(5) 存檔**

> **Jupyter**：可以在格子裡執行，每一行指令前面加 `!`。

```bash
git add .
git commit -m "Day 1: 設定 JupyterLab"
```

### 之後每天的開始方式

1. 開終端機，執行這三行（**一定要在終端機**）：

```bash
cd ~/Desktop/線上課程教材/pythan基礎觀念/爬蟲/好球帶研究室
source .venv/bin/activate
jupyter lab
```

2. 在 `notebooks/` 新增當天的筆記本（例如 `D03.ipynb`），Kernel 選「好球帶研究室 (.venv)」，第一格放每日開場程式碼。
3. 照當天教學做。每段程式碼前面都有標註要怎麼在 Jupyter 執行，或是一定要在終端機執行。

## 常見錯誤

| 狀況 | 原因與解法 |
| --- | --- |
| `command not found: streamlit` | 沒有啟動虛擬環境，先 `source .venv/bin/activate` |
| `pip install` 裝到別的地方 | 用 `which python` 確認路徑在 `.venv` 裡面 |
| `git push` 要求密碼 | GitHub 不再接受密碼，要用 Personal Access Token，或改用 GitHub Desktop |
