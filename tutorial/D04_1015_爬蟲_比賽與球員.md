## 第一部分：比賽結果與得失分

### 為什麼要做這一步

畢氏勝率（之後的系列賽預測就靠它）需要每隊的「得分」和「失分」。戰績表只有得失分差 `DIFF`，所以要從每場比賽的比分加總出來。

---

### 步驟

#### 1. 抓比賽結果

在 `src/fetch.py` 的 Day 3 區塊下面加上：

> **Jupyter**：新的一格，第一行寫 `%%writefile -a src/fetch.py`（`-a` 是加到檔案最後面，不會覆蓋），第二行留空，再貼這段。

```python
def fetch_games(season=SEASON, refresh=False):
    """每一場比賽的比分；只留下已經打完的。"""
    url = f"https://www.rebas.tw/api/seasons/{season}/games"
    data = cached_json(url, f"{season}_games.json", refresh=refresh)["data"]
    rows = []
    for g in data:
        if g["info"]["status"] != "FINISHED":
            continue
        rows.append({"game_id": g["uniqid"], "seq": g["seq"],
                     "date": g["info"]["scheduled_start_at"][:10],
                     "away": g["away"]["team"], "home": g["home"]["team"],
                     "away_runs": g["away"]["runs"], "home_runs": g["home"]["runs"],
                     "winner_side": g["info"]["winner_side"]})
    return pd.DataFrame(rows)
```

- 這個 API 會回傳 400 場，其中 40 場是延賽（`POSTPONED`），用 `continue` 跳過，只留下 360 場打完的。
- `scheduled_start_at` 長這樣：`"2026-10-06 18:35"`，`[:10]` 只取日期。
- `winner_side` 是 `HOME`（主隊贏）或 `AWAY`（客隊贏）。

#### 2. 用 `groupby` 算得分、失分

新增 `explore_runs.py` 來練習：

> **Jupyter**：直接貼在新的一格執行。

```python
from src import fetch

games = fetch.fetch_games()
print(games.shape)        # (360, 8)

# 主場：得分是 home_runs，失分是 away_runs
home = games.groupby("home").agg(RS=("home_runs", "sum"), RA=("away_runs", "sum"))
# 客場：得分是 away_runs，失分是 home_runs
away = games.groupby("away").agg(RS=("away_runs", "sum"), RA=("home_runs", "sum"))

runs = home.add(away, fill_value=0)
print(runs)
```

`groupby("home")` 的意思是「把主隊相同的比賽放在同一組」，`.agg(RS=("home_runs", "sum"))` 是「每一組把 `home_runs` 加總，新欄位叫 `RS`」。

`home.add(away)`：兩張表的 index 都是球隊名稱，`add` 會把同一隊的主場和客場數字相加。

#### 4. 練習：中職的主場優勢有多大？

台灣大賽的預測要用到「主場優勢」：主場球隊比較容易贏多少？不要用猜的，用資料算。`fetch_games()` 可以抓任何一年的比賽，算出每年**主場球隊的勝率**。

各年例行賽的賽季代碼：

| 年度 | 賽季代碼 |
| --- | --- |
| 2023 | `CPBL-2023-sk` |
| 2024 | `CPBL-2024-xa` |
| 2025 | `CPBL-2025-JO` |
| 2026 | `CPBL-2026-oB` |

提示：和局（`winner_side` 不是 `HOME` 也不是 `AWAY`）要先排除；`(g["winner_side"] == "HOME").mean()` 就是主場勝率。

<details>
<summary>參考解答</summary>

> **Jupyter**：直接貼在新的一格執行。

```python
total_home = total = 0
for season in ["CPBL-2023-sk", "CPBL-2024-xa", "CPBL-2025-JO", "CPBL-2026-oB"]:
    g = fetch.fetch_games(season)
    g = g[g["winner_side"].isin(["HOME", "AWAY"])]        # 排除和局
    home_wins = (g["winner_side"] == "HOME").sum()
    total_home += home_wins
    total += len(g)
    print(season, f"{len(g)} 場，主場勝率 {home_wins / len(g):.3f}")
print(f"四年合計 {total} 場，主場勝率 {total_home / total:.3f}")
```

- `g["winner_side"].isin([...])`：只留下值在清單裡的列，和局就被排除了。
- `(g["winner_side"] == "HOME")` 會變成一欄 True/False，`.sum()` 是 True 的個數，`.mean()` 是 True 的比例。

結果大約是：

| 年度 | 主場勝率 |
| --- | --- |
| 2023 | .529 |
| 2024 | .528 |
| 2025 | .545 |
| 2026 | .493 |
| 四年合計（1362 場） | **.523** |

中職確實有主場優勢：四年合計，主場球隊贏了 52.3%，比 50% 多約 **2.3 個百分點**。2026 年反而低於 5 成，代表單一球季的數字波動很大，所以用多年平均比較可靠。

</details>

我們的模型裡，主隊勝率 ＝ 中立場地勝率 ＋ 主場優勢，所以主場優勢就設成 **0.023**（下一步的設定檔會用到）。被問到「主場優勢怎麼來的」，就可以回答「中職 2023–2026 年 1362 場的主場勝率」。

## 第二部分：打者與投手成績

### 為什麼要做這一步

### 步驟

#### 2. 寫 `fetch_leaders`

加到 `src/fetch.py`：

> **Jupyter**：新的一格，第一行寫 `%%writefile -a src/fetch.py`（`-a` 是加到檔案最後面，不會覆蓋），第二行留空，再貼這段。

```python
# ---------- Day 4：打者、投手成績 ----------
def fetch_leaders(kind, season=SEASON, refresh=False):
    """kind = 'batter' 或 'pitcher'；把 standard 和 advanced 兩個 section 合併成一張表。"""
    frames = []
    for section in ["standard", "advanced"]:
        url = f"https://www.rebas.tw/api/seasons/{season}/leaders?type={kind}&section={section}&pa=undefined"
        data = cached_json(url, f"{season}_{kind}_{section}.json", refresh=refresh)["data"]
        df = pd.json_normalize(data)
        df = df.rename(columns={"player.uniqid": "player_id", "player.name": "name",
                                "player.team_abbr": "abbr"})
        frames.append(df)
    std, adv = frames
    keep = ["player_id"] + [c for c in adv.columns if c not in std.columns]
    out = std.merge(adv[keep], on="player_id", how="left")
    drop = [c for c in out.columns if c.startswith("player.")] + ["reach_min"]
    return out.drop(columns=[c for c in drop if c in out.columns])
```

重點解釋：

- `keep`：兩個 section 都有 `PA`、`games` 這些欄位，合併時重複的欄位會變成 `PA_x`、`PA_y`，很難用。所以 advanced 只留下「standard 沒有的欄位」。
- `merge(..., on="player_id", how="left")`：用球員代碼對齊兩張表。`how="left"` 代表以 standard 為主，standard 有的球員都會留下。
- 最後把用不到的欄位（大頭照網址、背號等）刪掉。
