### 1. 球種代碼與「出棒」

先在 `src/splits.py` 的 `NOT_COUNTED` 下面加兩個常數：

> **Jupyter**：新的一格，第一行寫 `%%writefile -a src/splits.py`（`-a` 是加到檔案最後面，不會覆蓋），第二行留空，再貼這段。（常數放在檔案最後面也沒關係，函式執行時才會用到它）

```python
BREAKING = {"SL", "CU", "CH", "FO", "FS", "SC", "SV", "KC"}  # 變化球與變速球（SI 伸卡是速球，不算）
SWING = {"SW", "F", "FT", "H"}  # 揮空、界外、擦棒、打進場內＝有出棒
```

| 代碼 | 球種 | 代碼 | 每一球的結果 |
| --- | --- | --- | --- |
| `FF` | 四縫線速球 | `B` | 壞球 |
| `SL` | 滑球 | `S` | 好球（沒揮） |
| `CU` | 曲球 | `SW` | 揮棒落空 |
| `CH` | 變速球 | `F` | 界外 |
| `FO` | 指叉球 | `H` | 打進場內 |

**揮空率 = 揮空 ÷ 出棒次數**。只看「有出棒」的球，才能看出打者揮了之後打不打得到。

### 2. 打擊習慣與投球習慣

加到 `src/splits.py`：

> **Jupyter**：新的一格，第一行寫 `%%writefile -a src/splits.py`（`-a` 是加到檔案最後面，不會覆蓋），第二行留空，再貼這段。

```python
def batter_hand(pa):
    """打者的打擊習慣：兩邊都打超過 10% 的打席就算左右開弓（S）。"""
    share = pa.groupby("batter_id")["b_hand"].value_counts(normalize=True).unstack(fill_value=0)
    def label(row):
        if row.get("L", 0) >= 0.1 and row.get("R", 0) >= 0.1:
            return "S"
        return "L" if row.get("L", 0) > row.get("R", 0) else "R"
    return share.apply(label, axis=1).rename("bats").reset_index()

def pitcher_hand(pa):
    return (pa.groupby("pitcher_id")["p_hand"].agg(lambda s: s.mode().iat[0])
            .rename("throws").reset_index())
```

- `value_counts(normalize=True)`：算比例而不是次數。
- `unstack(fill_value=0)`：把 L、R 變成兩個欄位，沒打過的那邊補 0。
- `s.mode().iat[0]`：取最常出現的值（眾數）。

### 3. 對變化球的揮空率

> **Jupyter**：新的一格，第一行寫 `%%writefile -a src/splits.py`（`-a` 是加到檔案最後面，不會覆蓋），第二行留空，再貼這段。

```python
def breaking_whiff(pa):
    """每位打者面對變化球時的揮空率＝揮空 ÷ 出棒。"""
    rows = []
    for bid, types, codes in pa[["batter_id", "pitch_types", "pitch_codes"]].itertuples(index=False):
        for t, c in zip(str(types).split(","), str(codes).split(",")):
            if t in BREAKING and c in SWING:
                rows.append((bid, c == "SW"))
    df = pd.DataFrame(rows, columns=["batter_id", "whiff"])
    out = df.groupby("batter_id")["whiff"].agg(swings="size", whiff_rate="mean").reset_index()
    return out
```

- `zip(types, codes)`：把「第幾球的球種」和「第幾球的結果」配成一對。
- `c == "SW"` 是 True/False，取平均就是揮空的比例。

### 4. 練習：投手的球種比例

寫 `pitch_mix(pa)`，回傳兩張表：

1. `mix`：每位投手每種球種的使用比例（欄位 `pitcher_id`、`pitch`、`share`）
2. `main`：每位投手最常用的**變化球**和比例（欄位 `pitcher_id`、`main_breaking`、`main_breaking_share`）

提示：跟 `breaking_whiff` 一樣先把每一球展開成一列，再 `groupby` + `value_counts(normalize=True)`；`main` 用 `sort_values` 後 `groupby(...).head(1)`。

```python
def pitch_mix(pa):
    """每位投手各球種的使用比例，以及最常用的變化球。"""
    rows = []
    for pid, types in pa[["pitcher_id", "pitch_types"]].itertuples(index=False):
        rows += [(pid, t) for t in str(types).split(",") if t and t != "nan"]
    df = pd.DataFrame(rows, columns=["pitcher_id", "pitch"])
    mix = df.groupby("pitcher_id")["pitch"].value_counts(normalize=True).rename("share").reset_index()
    brk = mix[mix["pitch"].isin(BREAKING)].sort_values("share", ascending=False)
    main = brk.groupby("pitcher_id").head(1).rename(columns={"pitch": "main_breaking",
                                                            "share": "main_breaking_share"})
    return mix, main
```

### 5. 全部包成 `build_splits`

把 Day 9 練習的寫法和今天的函式組起來，加到 `src/splits.py` 最下面：

> **Jupyter**：新的一格，第一行寫 `%%writefile -a src/splits.py`（`-a` 是加到檔案最後面，不會覆蓋），第二行留空，再貼這段。

```python
def build_splits(pa, scale):
    pa = prepare(pa, scale)
    # 打者：對左投、右投
    bvs = summarize(pa, ["batter_id", "p_hand"]).pivot(index="batter_id", columns="p_hand",
                                                      values=["PA", "wOBA"])
    bvs.columns = [f"{a}_vs{b}" for a, b in bvs.columns]
    batters = (bvs.reset_index().merge(batter_hand(pa), on="batter_id", how="left")
               .merge(breaking_whiff(pa), on="batter_id", how="left"))
    # 投手：對左打、右打，以及第 1、2、3 輪打線
    pvs = summarize(pa, ["pitcher_id", "b_hand"]).pivot(index="pitcher_id", columns="b_hand",
                                                       values=["PA", "wOBA"])
    pvs.columns = [f"{a}_vs{b}" for a, b in pvs.columns]
    tto = summarize(pa, ["pitcher_id", "pa_round"]).pivot(index="pitcher_id", columns="pa_round",
                                                         values="wOBA")
    tto.columns = [f"wOBA_round{int(c)}" for c in tto.columns]
    _, main = pitch_mix(pa)
    pitchers = (pvs.reset_index().merge(tto.reset_index(), on="pitcher_id", how="left")
                .merge(pitcher_hand(pa), on="pitcher_id", how="left")
                .merge(main, on="pitcher_id", how="left"))
    league = {"wOBA": pa["woba_val"].mean()}
    return batters, pitchers, league
```
