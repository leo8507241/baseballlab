### 2. 問題二：黃色長條上的白字看不清楚

戰力對比圖裡，中信兄弟的黃色長條配白字，幾乎看不到。不同球隊顏色深淺不同，要依照背景決定字的顏色。

在 `src/ui.py` 最後面加：

> **Jupyter**：新的一格，第一行寫 `%%writefile -a src/ui.py`（`-a` 是加到檔案最後面，不會覆蓋），第二行留空，再貼這段。

```python
def text_on(hex_color):
    """依背景色深淺決定文字用黑或白，淺色背景（例如兄弟的黃色）就用深色字。"""
    h = hex_color.lstrip("#")
    r, g, b = (int(h[i:i + 2], 16) for i in (0, 2, 4))
    return "#0D1520" if 0.299 * r + 0.587 * g + 0.114 * b > 150 else "#FFFFFF"
```

- `#f4cf46` 拆成紅 `f4`、綠 `cf`、藍 `46` 三段，`int(..., 16)` 把十六進位轉成 0–255 的數字。
- `0.299R + 0.587G + 0.114B` 是人眼感受到的亮度（綠色看起來最亮）。超過 150 算淺色，用深色字。

然後在戰力對比圖的兩個 `fig.add_bar(...)` 各加一個參數：

> **Jupyter**：這段要插進 `pages/predict.py` 的中間，不能用 `%%writefile`。在 JupyterLab 左側檔案列表雙擊打開 `pages/predict.py`，貼到指定位置，按 `Cmd + S` 存檔。（加在戰力對比圖兩個 `fig.add_bar(...)` 的括號裡）


### 3. 練習：整理重複的圖表樣式

搜尋整個專案的 `paper_bgcolor="rgba(0,0,0,0)"`，你會發現它出現了七、八次。重複的程式碼改起來很麻煩（想換字型就要改八個地方）。

在 `src/ui.py` 寫一個 `style_fig(fig, height=360, title=None)`：統一設定透明背景、字型（Noto Sans TC、文字顏色用 `COLORS["fg"]`）、邊距，有給標題就設定標題，最後回傳 `fig`。然後把各頁面重複的設定換成呼叫它。

<details>
<summary>參考解答</summary>

> **Jupyter**：新的一格，第一行寫 `%%writefile -a src/ui.py`（`-a` 是加到檔案最後面，不會覆蓋），第二行留空，再貼這段。

```python
def style_fig(fig, height=360, title=None):
    """全站圖表共用的外觀：透明背景、字型、邊距。"""
    fig.update_layout(height=height, paper_bgcolor="rgba(0,0,0,0)", plot_bgcolor="rgba(0,0,0,0)",
                      font=dict(family="Noto Sans TC, sans-serif", color=COLORS["fg"]),
                      margin=dict(t=50, l=10, r=10, b=10))
    if title:
        fig.update_layout(title=title)
    return fig
```

### 4. 手機版

Streamlit 的欄位在手機上會自動變成上下排列，但大數字可能太大。在 `src/ui.py` 的 `CSS` 裡，`</style>` 前面加：

> **Jupyter**：這段要插進 `src/ui.py` 的中間，不能用 `%%writefile`。在 JupyterLab 左側檔案列表雙擊打開 `src/ui.py`，貼到指定位置，按 `Cmd + S` 存檔。（要加在 `CSS` 字串裡、`</style>` 前面）

```css
@media (max-width: 640px) {
  .kpi-value { font-size: 30px; }
  .card { padding: 14px 16px; }
}
```

`@media (max-width: 640px)`：螢幕寬度 640px 以下（手機）才套用。
