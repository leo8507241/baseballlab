### 1. 實驗 4：資料截止日

如果我們在 8 月底、9 月中就做預測，結果會跟用完整例行賽差多少？

```python
# ---------- 實驗 4：資料截止日 ----------
def exp_cutoff(games, cutoffs=("2026-08-31", "2026-09-15", "2026-10-06")):
    a, b = config.TS_TEAMS
    rows = []
    for cut in cutoffs:
        g = games[games["date"] <= cut]
        rs_ra = {}
        for team in (a, b):
            home, away = g[g["home"] == team], g[g["away"] == team]
            rs_ra[team] = (home["home_runs"].sum() + away["away_runs"].sum(),
                           home["away_runs"].sum() + away["home_runs"].sum())
        pa, pb = pythag(*rs_ra[a]), pythag(*rs_ra[b])
        p = model.simulate_series(pa, pb, config.TS_HOME_PATTERN, config.TS_NEED, config.HOME_ADVANTAGE)[0]
        rows.append({"截止日": cut, "場數": len(g), f"{a} 畢氏勝率": pa, f"{b} 畢氏勝率": pb, "奪冠機率": p})
    return pd.DataFrame(rows)
```

差異來源：回頭看 Day 5 的半季戰績，中信兄弟上半季 20-38，下半季 36-24 拿下半季冠軍。他們後段變強，所以越晚的資料，兩隊差距越小。這說明了畢氏勝率用「整季」平均，會低估最近的狀態。這是很好的改進方向：例如讓近期比賽的權重高一點。

### 2. 實驗 5：實際結果檢驗

```python
# ---------- 實驗 5：實際結果檢驗 ----------
def exp_results(teams, post_games):
    """每場比賽：模型預測主隊勝率 vs 實際結果；計算命中率與 Brier score，並跟簡單方法比較。"""
    t = teams.set_index("team")
    rows = []
    for _, g in post_games.iterrows():
        if g["winner_side"] not in ("HOME", "AWAY"):
            continue
        p_home = model.game_prob(t.loc[g["home"], "pythag"], t.loc[g["away"], "pythag"], True,
                                 config.HOME_ADVANTAGE)
        home_won = g["winner_side"] == "HOME"
        better_home = t.loc[g["home"], "PCT"] >= t.loc[g["away"], "PCT"]
        rows.append({"日期": g["date"], "主隊": g["home"], "客隊": g["away"], "主隊勝率預測": p_home,
                     "主隊贏": home_won, "模型猜對": (p_home >= 0.5) == home_won,
                     "主場必勝猜對": home_won, "勝率高者必勝猜對": better_home == home_won})
    df = pd.DataFrame(rows)
    if df.empty:
        return df, {}
    summary = {
        "場數": len(df),
        "模型命中率": df["模型猜對"].mean(),
        "主場必勝命中率": df["主場必勝猜對"].mean(),
        "勝率高者必勝命中率": df["勝率高者必勝猜對"].mean(),
        "模型 Brier": ((df["主隊勝率預測"] - df["主隊贏"]) ** 2).mean(),
        "瞎猜 50% 的 Brier": 0.25,
    }
    return df, summary
```

- **命中率**：模型看好的球隊（勝率 ≥ 50%）有沒有贏。
- **Brier score**：(預測機率 − 實際結果)² 的平均，越小越好。永遠猜 50% 的 Brier 是 0.25，比 0.25 小才代表模型比瞎猜好。
- **簡單方法**：「主場球隊必勝」「戰績較好的球隊必勝」。模型如果連這些都贏不了，就要誠實寫出來。

### 3. 包成一支程式

`run_experiments.py` 在終端機執行，不是在網頁裡，但 `load()` 有 `@st.cache_data`，在終端機呼叫會出現警告。在 `src/data.py` 的 `load()` 上面加一個不經過快取的版本：

```python
def load_raw():
    """不經過 Streamlit 快取的版本，給 scripts/ 裡的程式用。"""
    return load.__wrapped__()
```

`load.__wrapped__`：`@st.cache_data` 會把原本的函式存在 `__wrapped__` 裡，直接呼叫它就跳過快取。

新增 `scripts/run_experiments.py`：

```python
"""上線後實驗：一次跑完五組穩定性實驗，印出報告並存成 data/clean/stability_summary.json。"""
import json
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
sys.path.insert(0, str(ROOT))
import pandas as pd

from src import config, fetch, stability as st
from src.data import load_raw

teams, batters, pitchers, const, lg = load_raw()
games = fetch.fetch_games()
pa = pd.read_csv(ROOT / "data/clean/pa.csv", dtype=str, keep_default_na=False)
a, b = config.TS_TEAMS
result = {}

# 實驗 1
s = st.exp_seeds(teams)
result["exp1"] = {"平均": s.mean(), "標準差": s.std(), "通過": bool(s.std() < 0.01)}

# 實驗 2
sens = st.exp_sensitivity(teams)
innings = {i: st.default_game_prob(teams, batters, pitchers, lg, sp_innings=i) for i in (5, 6, 7)}
spread = max(sens.groupby("參數")["奪冠機率"].agg(lambda x: x.max() - x.min()).max(),
             max(innings.values()) - min(innings.values()))
result["exp2"] = {"最大變動": spread, "先發局數": innings,
                  "看好的球隊不變": bool((sens["奪冠機率"] > 0.5).all() or (sens["奪冠機率"] < 0.5).all()),
                  "通過": bool(max(innings.values()) - min(innings.values()) <= 0.05)}

# 實驗 3
boot = st.exp_bootstrap_series(teams, games)
lo, hi = boot.quantile([0.025, 0.975])
result["exp3"] = {"奪冠機率95%區間": [lo, hi], "區間寬度": hi - lo, "通過": bool(hi - lo <= 0.10)}
stab = st.rule_stability_table(pa, const["woba_scale"], teams, batters, pitchers, lg)
stab.to_csv(ROOT / "data/clean/rule_stability.csv", index=False)
result["exp3"]["規則穩定比例"] = float((stab["ratio"] >= 0.8).mean())

# 實驗 4
cut = st.exp_cutoff(games)
drift = cut["奪冠機率"].max() - cut["奪冠機率"].min()
result["exp4"] = {"各截止日": cut["奪冠機率"].round(3).tolist(), "最大差距": drift, "通過": bool(drift <= 0.10)}

# 實驗 5
frames = []
for title in ("季後挑戰賽", "台灣大賽"):
    sid = fetch.find_season_id(2026, title)
    if sid:
        frames.append(fetch.fetch_games(sid, refresh=True))
post = pd.concat(frames) if frames else pd.DataFrame()
_, summary = st.exp_results(teams, post) if len(post) else (None, {})
result["exp5"] = summary

out = ROOT / "data/clean/stability_summary.json"
out.write_text(json.dumps(result, ensure_ascii=False, indent=1, default=float), encoding="utf-8")
for k, v in result.items():
    print(k, json.dumps(v, ensure_ascii=False, default=lambda x: round(float(x), 3)))
```
