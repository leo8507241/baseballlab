## 第一部分：好壞標準與計算機

### 為什麼要做這一步

「wOBA .350 算好嗎？」光看數字很難判斷。把它放到全聯盟的分布裡，一眼就知道「比 75% 的打者好」。好壞標準用**中職今年的真實分布**，而不是大聯盟的標準，這也是跟其他網站不一樣的地方。

### 步驟

#### 1. 計算機的設定

在 `pages/academy.py` 的 `TABLES = ...` 下面加：

```python
# 每個數據的計算機：輸入欄位（名稱、預設值）＋計算方式
CALC = {
    "wOBA": ([("1B", 90), ("2B", 25), ("3B", 3), ("HR", 15), ("BB", 48), ("IBB", 3), ("HBP", 5), ("AB", 480), ("SF", 4)],
             lambda v: metrics.woba(v["BB"] - v["IBB"], v["HBP"], v["1B"], v["2B"], v["3B"], v["HR"],
                                    v["AB"], v["BB"], v["IBB"], v["SF"], const["woba_scale"])),
    "ISO": ([("AB", 480), ("2B", 25), ("3B", 3), ("HR", 15)],
            lambda v: metrics.iso(v["2B"], v["3B"], v["HR"], v["AB"])),
    "BABIP": ([("H", 135), ("HR", 15), ("AB", 480), ("SO", 85), ("SF", 4)],
              lambda v: metrics.babip(v["H"], v["HR"], v["AB"], v["SO"], v["SF"])),
    "FIP": ([("IP", 150), ("HR", 12), ("BB", 40), ("SO", 130)],
            lambda v: metrics.fip(v["HR"], v["BB"], v["SO"], v["IP"], const["fip_const"])),
}
```

每個計算機是一組 `(輸入欄位, 計算函式)`：

- 輸入欄位：`(名稱, 預設值)` 的清單
- 計算函式：收到 `{"AB": 480, "HR": 15, ...}` 這樣的字典，回傳結果。直接呼叫 `metrics.py` 的公式，**同一個公式不寫第二遍**。
- wOBA 要乘倍數、FIP 要加常數，都從 `const`（Day 7 存的 `league_constants.csv`）讀。

#### 2. 輸入欄位

接在昨天的公式區塊後面（注意縮排，要在 `with main:` 裡面）：

```python
    result = None
    if key in CALC:                      # 有計算機的數據才顯示輸入欄位
        st.subheader("自己算算看")
        fields, fn = CALC[key]
        cols = st.columns(len(fields))
        vals = {name: cols[i].number_input(name, min_value=0.0, value=float(d), key=f"{key}_{name}")
                for i, (name, d) in enumerate(fields)}
        try:
            result = fn(vals)
        except ZeroDivisionError:
            st.warning("分母是 0，請檢查輸入的數字。")
```

- `st.columns(len(fields))`：有幾個輸入欄位就切幾欄，排成一列。
- 字典推導式 `{name: ... for ...}` 一次建好所有輸入框，回傳 `{"AB": 480.0, ...}`。
- `key=f"{key}_{name}"`：wOBA 和 ISO 都有 `AB` 欄位，`key` 要不一樣。
- `try/except ZeroDivisionError`：使用者把打數改成 0 時不會讓整頁壞掉。
- 有些數據（例如 OPS+）不適合手算，`if key in CALC` 讓它們只顯示分布圖。

### 寫作原則

1. **一句話定義**：不用術語解釋術語。「每 100 個打席中有幾次保送」比「BB 除以 PA」好懂。
2. **為什麼需要它**：先說傳統數據哪裡不夠，再說這個數據補了什麼。
3. **什麼時候用**：給一個具體情境，例如「三振率突然上升，常是狀況下滑的第一個訊號」。
4. 不要超過 3 句。寫完唸出來，唸起來卡卡的就改。
