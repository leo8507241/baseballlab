### 2. 常見問題與解法

| 狀況 | 原因 | 解法 |
| --- | --- | --- |
| `ModuleNotFoundError: No module named 'plotly'` | `requirements.txt` 少寫套件 | 補上後重新上傳 |
| `FileNotFoundError: data/clean/...` | 檔案沒上傳，或 `.gitignore`／`ignore_patterns` 排除了 | 檢查 Space 的「Files」分頁有沒有這個檔案 |
| 本機正常、線上找不到檔案 | Linux 大小寫有差，`Teams.csv` 和 `teams.csv` 是不同檔案 | 統一用小寫檔名 |
| 線上跟本機畫面不一樣 | Streamlit 版本不同 | `README.md` 的 `sdk_version` 要跟 `requirements.txt` 一樣 |
| 很久沒人用，打開要等 | 免費 Space 閒置會休眠 | 正常現象，等 1 分鐘會醒來 |

看錯誤細節：Space 頁面右上角「⋮」→「Logs」，最下面通常就是錯誤原因。

### 3. 不要在上線版即時爬資料

預測頁的「賽後對照」是開頁時才去野球革命抓台灣大賽結果。這有兩個風險：

1. 對方網站沒回應時，整個預測頁會壞掉
2. 每位訪客都會去打對方的 API

台灣大賽已經打完，結果不會再變了，所以改成在 `update_data.py` 抓好、存成檔案。

在 `scripts/update_data.py` 最後面加上：

> **Jupyter**：新的一格，第一行寫 `%%writefile -a scripts/update_data.py`（`-a` 是加到檔案最後面，不會覆蓋），第二行留空，再貼這段。

```python
# 台灣大賽打完後，把結果也存起來，網站就不用即時去抓
season_id = fetch.find_season_id(2026, "台灣大賽")
if season_id:
    post = fetch.fetch_games(season_id, refresh=True)
    post.to_csv(ROOT / "data/clean/postseason.csv", index=False)
    print(f"台灣大賽 {len(post)} 場")
```

### 4. 練習：頁面先讀檔案，讀不到再抓，抓不到也不壞

修改 `pages/predict.py` 的 `postseason_games()`：

1. 如果 `data/clean/postseason.csv` 存在，直接讀它
2. 不存在的話才去野球革命抓
3. 抓的時候出任何錯誤，都回傳 `None`（頁面就會顯示「還沒更新」的提示），並在終端機印出錯誤

提示：`from pathlib import Path` 加在檔案最上面；錯誤處理用 `try/except Exception as e`。

<details>
<summary>參考解答</summary>

> **Jupyter**：這段要插進 `pages/predict.py` 的中間，不能用 `%%writefile`。在 JupyterLab 左側檔案列表雙擊打開 `pages/predict.py`，貼到指定位置，按 `Cmd + S` 存檔。（把原本的 `postseason_games()` 整個函式換成這一版）

```python
@st.cache_data(ttl=3600)  # 一小時內重複開頁不會再去抓
def postseason_games():
    saved = Path(__file__).resolve().parent.parent / "data" / "clean" / "postseason.csv"
    if saved.exists():               # 優先讀 update_data.py 存好的檔案
        return pd.read_csv(saved)
    try:
        season_id = fetch.find_season_id(2026, config.POSTSEASON_TITLE)
        return fetch.fetch_games(season_id, refresh=True) if season_id else None
    except Exception as e:          # 網路不通或對方網站沒回應時，不要讓整頁壞掉
        print(f"抓不到季後賽資料：{e}")
        return None
```
