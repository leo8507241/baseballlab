### 2. 檢查要上傳什麼

> **Jupyter**：可以在格子裡執行，每一行指令前面加 `!`（例如 `!python scripts/update_data.py`）。

- `data/raw/`（約 4MB）：**不要**上傳，隨時可以重新抓，已經在 `.gitignore` 裡
- `tutorial/`：可以不上傳到 Space（網站用不到），但要留在 GitHub

先把所有東西推上 GitHub：

> **一定要在終端機執行**：第一次推送可能要輸入帳號和 token，`!` 沒辦法輸入。在 JupyterLab 用 **File → New → Terminal** 開一個終端機執行。


### 3. Space 的設定檔

Hugging Face 用 `README.md` 最上面的設定區塊決定怎麼跑網站。把 `README.md` 的最上面改成（如果還沒有 README 就新增）：

> **Jupyter**：這段要插進 `README.md` 的中間，不能用 `%%writefile`。在 JupyterLab 左側檔案列表雙擊打開 `README.md`，貼到指定位置，按 `Cmd + S` 存檔。（如果專案根目錄還沒有 `README.md`，可以直接用 `%%writefile README.md` 建立）

```yaml
---
title: 好球帶研究室
emoji: ⚾
colorFrom: yellow
colorTo: blue
sdk: streamlit
sdk_version: 1.51.0
python_version: "3.12"

```

- `sdk_version`：跟 `requirements.txt` 的 Streamlit 版本一樣
- `python_version`：numpy 2.3 需要 Python 3.11 以上，所以指定 3.12
- `app_file`：網站入口

三條 `---` 之間的設定區塊下面，可以接著寫一般的說明文字（Day 33 再寫完整的 README）。

### 4. 建立 Space

1. 登入 [Hugging Face](https://huggingface.co/)，右上角「New」→「Space」
2. Space name：`haoqiudai-lab`；SDK 選 **Streamlit**；硬體選免費的 CPU basic
3. 到「Settings → Access Tokens」建立一個 **Write** 權限的 token，複製下來（只會顯示一次）

### 5. 上傳

安裝上傳工具（只在你的電腦用，不用寫進 `requirements.txt`）：

> **一定要在終端機執行**：`hf auth login` 要貼上 token，`!` 沒辦法輸入。在 JupyterLab 用 **File → New → Terminal** 開一個終端機執行。

```bash
pip install huggingface_hub
hf auth login          # 貼上剛剛的 token
```

新增 `scripts/deploy.py`：

> **Jupyter**：新的一格，第一行寫 `%%writefile scripts/deploy.py`，下面貼這段，執行後就會存成檔案（會覆蓋同名檔案）。

```python
"""把網站上傳到 Hugging Face Space。用法：python scripts/deploy.py"""
from pathlib import Path

from huggingface_hub import HfApi

ROOT = Path(__file__).resolve().parent.parent
SPACE = "<你的帳號>/haoqiudai-lab"

HfApi().upload_folder(
    folder_path=str(ROOT), repo_id=SPACE, repo_type="space",
    ignore_patterns=[".venv/*", "data/raw/*", "tutorial/*", "tests/*", ".git/*", "notebooks/*",
                     "**/__pycache__/*", "**/.ipynb_checkpoints/*", "explore*.py", ".DS_Store"],
    commit_message="更新網站",
)
print(f"上傳完成：https://huggingface.co/spaces/{SPACE}")
```

> **Jupyter**：可以在格子裡執行，每一行指令前面加 `!`（例如 `!python scripts/update_data.py`）。

```bash
python scripts/deploy.py
```

`ignore_patterns`：不上傳的檔案。特別注意 `.venv/*`（虛擬環境有好幾百 MB），不排除的話會上傳很久。

### 6. 看它跑起來

打開 Space 的網址，上方會顯示「Building」，大約 2–5 分鐘後變成「Running」，就能看到網站了。

Building 的時候點「Logs」可以看安裝過程，如果失敗，錯誤訊息會在這裡。明天專門處理部署會遇到的問題。

## 常見錯誤

| 狀況 | 原因與解法 |
| --- | --- |
| `401 Unauthorized` | token 沒有 Write 權限，重新建立一個 |
| 上傳很久 | 檢查 `ignore_patterns`，可能把 `.venv` 傳上去了 |
| Space 一直 Building 後失敗 | 看 Logs，通常是套件版本問題，明天處理 |
