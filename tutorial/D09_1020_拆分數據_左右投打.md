## 步驟

### 1. 每個打席值多少 wOBA

wOBA 其實可以想成「每個打席的平均得分價值」：一安值 0.89、全壘打值 2.10、出局值 0。所以只要把每個打席的結果換成分數，再取平均，就是 wOBA。

新增 `src/splits.py`：

> **Jupyter**：新的一格，第一行寫 `%%writefile src/splits.py`，下面貼這段，執行後就會存成檔案（會覆蓋同名檔案）。

```python
"""從逐打席資料（data/clean/pa.csv）算出拆分數據：對左右投打、第幾輪打線、對變化球揮空率。"""
import pandas as pd

from src.metrics import WOBA_WEIGHTS

# 打席結果代碼 → wOBA 權重（沒列出的都是出局，權重 0）
RESULT_WEIGHT = {"uBB": WOBA_WEIGHTS["uBB"], "HBP": WOBA_WEIGHTS["HBP"], "1B": WOBA_WEIGHTS["1B"],
                 "2B": WOBA_WEIGHTS["2B"], "3B": WOBA_WEIGHTS["3B"], "HR": WOBA_WEIGHTS["HR"]}
# 不算進 wOBA 分母的打席：故意四壞、犧牲觸擊、資料空白
NOT_COUNTED = {"IBB", "SH", "SH_E", "", "nan"}

def prepare(pa, scale):
    pa = pa.copy()
    pa["result"] = pa["result"].fillna("").astype(str)
    pa = pa[~pa["result"].isin(NOT_COUNTED)]
    pa["woba_val"] = pa["result"].map(RESULT_WEIGHT).fillna(0) * scale
    pa["pa_round"] = pd.to_numeric(pa["pa_round"], errors="coerce").clip(upper=3)  # 第 3 輪以後合併
    return pa

def summarize(pa, keys):
    g = pa.groupby(keys)
    return g.agg(PA=("woba_val", "size"), wOBA=("woba_val", "mean")).reset_index()
```

- `.map(RESULT_WEIGHT)`：把 `"1B"` 換成 0.89，字典裡沒有的（出局）會變成 `NaN`，再用 `fillna(0)` 補 0。
- `* scale`：乘上 Day 7 的倍數，讓這裡的 wOBA 跟 `batters.csv` 是同一個尺度。
- `clip(upper=3)`：第 4 輪很少見，併進第 3 輪一起算。
- `summarize`：依照指定的欄位分組，算打席數和平均 wOBA。

### 2. 驗證：整個聯盟的 wOBA

> **Jupyter**：直接貼在新的一格執行。

```python
import pandas as pd
from src import splits

pa = pd.read_csv("data/clean/pa.csv", dtype=str, keep_default_na=False)
const = pd.read_csv("data/clean/league_constants.csv", index_col=0).iloc[:, 0]
p = splits.prepare(pa, const["woba_scale"])
print(p["woba_val"].mean())     # 應該約 0.319
```

0.319 剛好等於聯盟上壘率，代表 Day 7 的倍數和今天的計算是一致的。

### 3. 長表變寬表

> **Jupyter**：直接貼在新的一格執行。

```python
s = splits.summarize(p, ["batter_id", "p_hand"])
print(s.head())
```

這是「長表」：同一位打者有兩列（對左投一列、對右投一列）。網站要的是「寬表」，一位打者一列：

> **Jupyter**：直接貼在新的一格執行。

```python
wide = s.pivot(index="batter_id", columns="p_hand", values=["PA", "wOBA"])
wide.columns = [f"{a}_vs{b}" for a, b in wide.columns]
print(wide.head())      # 欄位：PA_vsL, PA_vsR, wOBA_vsL, wOBA_vsR
```

`pivot` 之後欄位會變成兩層 `("PA", "L")`，用一行 list comprehension 合併成 `PA_vsL` 這種好讀的名字。

### 4. 練習：投手的拆分

### 5. 小提醒：樣本數
