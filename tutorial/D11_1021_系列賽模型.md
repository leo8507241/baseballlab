## 步驟

### 1. Log5

如果 A 隊實力是 0.578、B 隊是 0.508，A 贏 B 的機率不是 0.578，因為 0.578 是「對全聯盟平均球隊」的勝率。Log5 公式把兩邊都考慮進去：

```text
P(A 勝) = (A − A×B) ÷ (A + B − 2×A×B)
```

新增 `src/model.py`：

> **Jupyter**：新的一格，第一行寫 `%%writefile src/model.py`，下面貼這段，執行後就會存成檔案（會覆蓋同名檔案）。

```python
"""台灣大賽預測模型：系列賽（畢氏勝率＋Log5＋蒙地卡羅）與單場（打線 vs 投手的預估得分）。"""
import numpy as np

from src.metrics import pythag

# ---------- Day 11：系列賽 ----------
def log5(pa, pb):
    """A 隊實力 pa、B 隊實力 pb 時，A 贏 B 的機率。"""
    return (pa - pa * pb) / (pa + pb - 2 * pa * pb)

def game_prob(pa, pb, a_is_home, hfa=0.03):
    p = log5(pa, pb) + (hfa if a_is_home else -hfa)
    return min(max(p, 0.05), 0.95)
```

- `hfa`（home field advantage）：主場加 3%，客場減 3%。
- `min(max(p, 0.05), 0.95)`：把機率限制在 5%–95%，棒球沒有穩贏的比賽。

### 2. 蒙地卡羅模擬

「蒙地卡羅」就是用大量隨機實驗來估機率。每一場用亂數決定勝負：亂數小於 A 的勝率就算 A 贏。

> **Jupyter**：新的一格，第一行寫 `%%writefile -a src/model.py`（`-a` 是加到檔案最後面，不會覆蓋），第二行留空，再貼這段。

```python
def simulate_series(pa, pb, home_pattern, need=4, hfa=0.03, n=10_000, seed=2026):
    """
    模擬整個系列賽 n 次，回傳 A 隊奪冠機率和每種結果（4-0、4-1……）的次數。
    home_pattern：A 隊每一場是否為主場，例如 [True, True, False, False, True, True, True]。
    """
    rng = np.random.default_rng(seed)
    probs = [game_prob(pa, pb, h, hfa) for h in home_pattern]
    a_titles = 0
    results = {}
    for _ in range(n):
        wa = wb = 0
        for p in probs:
            if rng.random() < p:
                wa += 1
            else:
                wb += 1
            if wa == need or wb == need:
                break
        a_titles += wa == need
        key = f"{wa}-{wb}"
        results[key] = results.get(key, 0) + 1
    return a_titles / n, results, probs
```

- `np.random.default_rng(seed)`：固定 `seed`，每次執行結果都一樣，網頁才不會每次重新整理數字就變。
- `if wa == need or wb == need: break`：有一隊先拿到 4 勝，系列賽就結束。
- `a_titles += wa == need`：`True` 會被當成 1 加上去。
- `results`：記錄每種比數出現幾次，例如 `{"4-2": 1876, ...}`。

3. 用遞迴計算「目前 a 勝 b 敗、打到第 g 場」時最後奪冠的機率：

> **Jupyter**：直接貼在新的一格執行。

```python
from functools import lru_cache

def exact_series(probs, need=4):
    @lru_cache(None)
    def f(g, wa, wb):
        if wa == need: return 1.0
        if wb == need: return 0.0
        p = probs[g]
        return p * f(g + 1, wa + 1, wb) + (1 - p) * f(g + 1, wa, wb + 1)
    return f(0, 0, 0)

print(exact_series(tuple(probs)))
```

結果會跟模擬非常接近。網站還是用模擬，因為「跑 10,000 次」比遞迴更好跟讀者解釋，也能順便得到 4-0、4-1 的分布。
