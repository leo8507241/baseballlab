## 今天的目標

- 用四條規則自動幫球員貼標籤：異軍突起、被低估、泡沫警示、真的退步
- 用卡片顯示每隊的話題球員

## 為什麼要做這一步

這是你一開始就想做的主題：「有些人值得期待但今年沒繳出成績，有些人異軍突起」。關鍵是分辨**實力變化**和**運氣變化**：

| 標籤 | 條件 | 為什麼可信 |
| --- | --- | --- |
| 異軍突起 | wOBA 比去年高 .030 以上 | 一起看三振率、保送率有沒有進步，有的話是真的變強 |
| 被低估 | ERA 比 FIP 高 0.5 以上 | FIP 不受守備和運氣影響，ERA 高是被拖累 |
| 泡沫警示 | BABIP 比去年高 .030 以上 | BABIP 很受運氣影響，通常會回到原本的水準 |
| 真的退步 | 三振率比去年少 3 個百分點以上 | 三振率幾乎不受運氣影響，下滑就是實力問題 |

### 1. 抓去年的成績

`fetch_leaders` 本來就可以指定賽季。2025 年例行賽的代碼是 `CPBL-2025-JO`。在 `src/clean.py` 的 `main()` 上面加：

> **Jupyter**：這段要插進 `src/clean.py` 的中間，不能用 `%%writefile`。在 JupyterLab 左側檔案列表雙擊打開 `src/clean.py`，貼到指定位置，按 `Cmd + S` 存檔。（要放在 `main()` 上面；放到檔案最後的話，執行 `main()` 時這個函式還沒定義，會出錯）

```python
def build_previous(season="CPBL-2025-JO"):
    """上一季的成績，用來判斷「異軍突起」「真的退步」。"""
    b = fetch.fetch_leaders("batter", season)[["player_id", "PA", "wOBA", "BABIP", "Kp", "BBp"]]
    p = fetch.fetch_leaders("pitcher", season)[["player_id", "IPOut", "ERA", "FIP", "Kp", "BBp"]]
    return b.add_prefix("prev_").rename(columns={"prev_player_id": "player_id"}), \
        p.add_prefix("prev_").rename(columns={"prev_player_id": "player_id"})
```

`add_prefix("prev_")`：所有欄位前面加 `prev_`，合併後才分得出今年的 `wOBA` 和去年的 `prev_wOBA`。但 `player_id` 要改回來，才能用來合併。

在 `main()` 裡，存檔之前加上合併：

> **Jupyter**：這段要插進 `src/clean.py` 的中間，不能用 `%%writefile`。在 JupyterLab 左側檔案列表雙擊打開 `src/clean.py`，貼到指定位置，按 `Cmd + S` 存檔。（要放在 `main()` 裡面、存檔之前）

### 2. 第一個標籤：異軍突起

接在 `pages/watch.py` 後面：

> **Jupyter**：新的一格，第一行寫 `%%writefile -a pages/watch.py`（`-a` 是加到檔案最後面，不會覆蓋），第二行留空，再貼這段。

```python
# ---------- Day 20：話題球員標籤 ----------
st.header("本季話題球員")
tb = batters[(batters["abbr"] == abbr) & (batters["PA"] >= 150)]
tpit = pitchers[(pitchers["abbr"] == abbr) & (pitchers["IP"] >= 30)]
tags = []
rise = tb[(tb["prev_PA"] >= 100)].assign(d=lambda d: d["wOBA"] - d["prev_wOBA"]).nlargest(1, "d")
if len(rise) and rise.iloc[0]["d"] >= 0.030:
    r = rise.iloc[0]
    tags.append(("good", "異軍突起", r["name"], f"wOBA {ui.f3(r['wOBA'])}（去年 {ui.f3(r['prev_wOBA'])}）",
                 f"三振率 {r['prev_Kp']:.1f}% → {r['Kp']:.1f}%，保送率 {r['prev_BBp']:.1f}% → {r['BBp']:.1f}%。"))
```

- 每一隊**只挑最明顯的一位**（`nlargest(1, ...)`），而且要超過門檻才算。
- `tags` 裡每一筆是 `(顏色, 標籤, 名字, 數字, 說明)`，最後統一畫成卡片。
- 這裡比較的是野球革命的 `wOBA`（兩年都用同一個來源，才能公平比較）。

### 3. 練習：另外三個標籤

照著「異軍突起」的寫法，完成另外三個（條件見上面的表格）：

- **被低估**（`cold`）：從 `tpit` 找 `ERA - FIP_calc` 最大的投手，差距 ≥ 0.5
- **泡沫警示**（`hot`）：從 `tb` 找 `BABIP - prev_BABIP` 最大的打者，差距 ≥ .030
- **真的退步**（`bad`）：從去年投超過 30 局（`prev_IPOut >= 90`）的投手中，找 `Kp - prev_Kp` 最小的，差距 ≤ −3

最後用兩欄卡片顯示 `tags`，沒有任何標籤時顯示「這一隊沒有符合條件的話題球員」。

cols = st.columns(2)
for i, (tone, label, name, nums, why) in enumerate(tags):
    with cols[i % 2]:
        st.markdown(f'<div class="card">{ui.chip(label, tone)}<h4 style="margin:8px 0 2px">{name}</h4>'
                    f'<div class="num" style="font-size:20px">{nums}</div>'
                    f'<div class="kpi-label">{why}</div></div>', unsafe_allow_html=True)

    st.caption("這一隊沒有符合條件的話題球員。")

### 4. 檢查標籤合不合理

切換六隊，看看被貼標籤的球員。你是球迷，對這些球員今年的表現應該有印象：

- 標籤跟你的印象一致嗎？
- 有沒有明顯該出現卻沒出現的人？（可能門檻太嚴，或打席數不夠被排除了）

你應該會發現：**同一位打者可能同時被貼上「異軍突起」和「泡沫警示」**。例如統一獅的陳重羽，wOBA 從 .233 升到 .356，BABIP 也從 .234 升到 .363。這代表他的進步有一大部分來自「打進場內的球剛好落地」，不一定是實力變強。

**加分練習**：遇到這種情況，把「異軍突起」的說明改成「進步明顯，但 BABIP 也大幅上升，需要觀察能不能維持」。提示：先算出 `bubble`，再回頭檢查 `rise` 的球員是不是同一個人（比較 `player_id`）。
